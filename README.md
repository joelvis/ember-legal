# Ember legal pages

Public privacy policy and support pages for **Ember: Sleep & Meditation** (iOS), served by GitHub Pages.

- `privacy.html` → https://joelvis.github.io/ember-legal/privacy.html
- `support.html` → https://joelvis.github.io/ember-legal/support.html

These URLs are entered in App Store Connect. The editable source lives in the private EmberTimer repository under `docs/` (HTML) and `EmberTimer/Release/EMBER_PRIVACY_POLICY.md` (text). When the policy changes, update those, copy the HTML here, and push.
